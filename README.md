# PDF Studio – Offline PDF Editor

PDF Studio is a browser-based PDF editing application that allows users to manage and manipulate PDF documents directly in their browser without requiring an internet connection.

The application provides a collection of PDF tools through a simple and user-friendly interface. It is designed to make common PDF operations convenient, accessible, and efficient.

## Live Demo

https://trishita924.github.io/offline-pdf-editor/

## Features

- **Upload & Preview:** Upload PDF documents and preview their pages.
- **Merge PDFs:** Combine multiple PDF files into a single document.
- **Split PDFs:** Separate PDF pages into individual documents.
- **Reorder Pages:** Change the order of pages.
- **Rotate & Delete Pages:** Rotate or remove selected pages.
- **Extract & Duplicate Pages:** Extract or duplicate specific pages.
- **PDF Editing:** Add text, images, highlights, drawings, and other annotations.
- **Watermark & Page Numbers:** Add watermarks, page numbers, headers, and footers.
- **PDF Conversion:** Convert images to PDF, PDF pages to images, and PDF content to text.
- **PDF Utilities:** Compress PDFs, manage document details, and compare PDF files.
- **Offline Support:** Perform PDF operations without requiring an active internet connection.

## Technologies Used

- HTML
- CSS
- JavaScript
- Vite

- PDF.js

## How to Use

1. Open the live application.
2. Upload your PDF document.
3. Select the required PDF operation.
4. Make the desired changes.
5. Download the processed PDF.

## Offline Functionality

PDF Studio is designed to work locally in the browser. Once the application and its required resources are loaded, PDF operations can be performed without an internet connection. Your PDF processing does not require uploading documents to an external server.
