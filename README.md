# PDF Studio

A professional, 100% offline PDF editor and organiser web application built with HTML, CSS, Vanilla JavaScript, Vite, PDF.js, and pdf-lib.

## Features
- 🔒 **100% Local Processing:** All PDF operations run directly in your browser. No cloud uploads, external APIs, or database required.
- 📂 **Multi-file Upload & Merge:** Open and merge multiple PDF documents seamlessly.
- 🖼️ **Page Thumbnails & Sidebar:** Interactive sidebar with high-performance rendered page previews.
- ⇄ **Drag-and-Drop Reordering:** Easily rearrange pages across single or multiple documents.
- 🔄 **Rotate Pages:** Rotate selected pages by 90°, 180°, or 270°.
- 🗑️ **Delete & Duplicate Pages:** Remove unwanted pages or duplicate selected sheets instantly.
- 📄 **Insert Blank Pages:** Add custom blank pages matching existing or standard paper sizes.
- ✂️ **Crop Pages:** Trim margins precisely using percentage controls.
- 📤 **Extract & Split:** Export subsets of pages or split documents by ranges or individual files.
- ⚡ **Works Offline:** Fully bundled assets with local PDF.js worker support.

## Getting Started

1. Clone or download this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL displayed in your terminal (typically `http://localhost:5173`).
